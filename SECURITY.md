# Security Policy

## Supported Versions

We fully support only *current* version of tools

| Version | Supported          |
| ------- | ------------------ |
| current  | :white_check_mark: |
| older  | :x:                |

## Reporting a Vulnerability

Our project depends on many otheer projects. In case of vulnerability of few of them,
we'll wating for hotfixes for it.
In case you find vulnerability in our project itself, please report it to Issues section.
we'll accept such request almost during 1-2 days. Unfortunitally we cannot predicate time to fix your issue
